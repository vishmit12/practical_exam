📖 About the Project

Retail Sales Analysis Using Python is a data analysis project that transforms raw retail transaction records into meaningful business insights.

The project uses a sample retail dataset containing product names, categories, quantities sold, unit prices, and transaction dates.

Using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn, the project cleans sales data, calculates revenue, analyzes product performance, and creates informative charts.

It also includes a reusable RetailSalesAnalyzer class that supports sales reporting, product filtering, metric calculation, and adding new transactions.

The project is ideal for students, Python beginners, aspiring data analysts, and anyone interested in data analytics.

🎯 Project Objectives
Clean and preprocess retail sales data.
Calculate total sales revenue automatically.
Analyze product-wise and category-wise performance.
Calculate important statistical measures.
Identify sales patterns over time.
Create clear and informative data visualizations.
Add new sales transactions and save them to a CSV file.
Practice object-oriented programming in Python.

🧮 Sales Calculation

Each transaction's revenue is calculated using:

python
data["Sales"] = data["Quantity"] * data["Unit_Price"]


For example, selling two laptops at ₹50,000 each generates ₹1,00,000 in revenue.

📈 Data Visualizations

The project generates four visualizations to explore retail performance.

1. 💰 Total Revenue by Product

A bar chart compares total revenue generated by each product, making it easy to identify the highest-revenue products.

2. 📅 Sales Revenue Over Time

A line chart displays transaction revenue across dates and helps reveal changes in sales activity.

3. 🥧 Revenue Distribution by Product

A pie chart illustrates each product's percentage contribution to total revenue.

4. 🔥 Retail Sales Correlation Heatmap

A Seaborn heatmap displays correlations between quantity, unit price, and sales.

🚀 How to Run

Run the Python script:

bash
python retail_sales.py


The program will create the CSV dataset, load and clean the records, calculate sales metrics, generate reports, display statistical summaries, and produce visualizations.

Important: Your current code creates retail_sales.csv before reading it. If you run the complete script repeatedly, the initial dataset will be recreated, potentially overwriting previously saved transactions. For persistent records, separate dataset initialization from the analysis script.

🧪 Example Usage
Initialize the Analyzer
python
analyzer = RetailSalesAnalyzer("retail_sales.csv")

Calculate Sales Metrics
python
analyzer.calculate_metrics()


This displays:

Total revenue
Total units sold
Average transaction revenue
Total number of transactions
Filter Laptop Transactions
python
laptop_sales = analyzer.filter_products("Laptop")
print(laptop_sales)

Filter Accessories
python
accessory_sales = analyzer.filter_category("Accessories")
print(accessory_sales)

Generate a Sales Report
python
analyzer.generate_report()


The report includes the transaction data, revenue by product, revenue by category, and quantity sold by product.

Calculate Statistical Measures
python
sales = analyzer.df["Sales"].to_numpy()

print("Average Sales:", np.mean(sales))
print("Maximum Sale:", np.max(sales))
print("Minimum Sale:", np.min(sales))
print("Total Sales:", np.sum(sales))
print("Standard Deviation:", np.std(sales))

Add a New Transaction
python
analyzer.log_sale(
    product="Mouse",
    category="Accessories",
    quantity=5,
    unit_price=800
)


This adds a transaction for five mice at ₹800 per unit, calculates revenue, and saves the updated dataset.

The new transaction has a total sales value of ₹4,000.

📉 Key Metrics

The analyzer calculates the following business metrics:

Metric	Meaning
Total Revenue	Sum of all transaction sales
Total Units Sold	Sum of all quantities
Average Sale Value	Average revenue per transaction
Total Transactions	Number of transaction records
Maximum Sale	Highest transaction revenue
Minimum Sale	Lowest transaction revenue
Standard Deviation	Variation in transaction revenue

Note: Average sale value in this implementation means the average revenue per transaction record, not the average price per unit.
